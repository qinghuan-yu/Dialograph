# 合成侧写恢复评测

这是对现有完整 agent 的外部评测，不改变分析提示词。评测结论限于合成对话中的行为设定恢复，不代表真实人格测量效度。

## 运行

在项目根目录配置 `.env` 后运行：

```powershell
python agent/evaluate_persona.py --workers 3
```

默认生成6组行为设定×2个场景变体，以及2份信息不足对照。每份主实验对话目标48条消息，调用现有完整工作流生成证据、关系分析和人物报告。生成、分析、盲法标签提取都会调用配置的模型API并产生费用。仅使用新建虚构数据，不读取 `talks/` 中的个人对话。

产物写入被Git忽略的 `analysis/evaluation_20261017/`：

- `manifest.json`：调用前固定的本体、真值、判据、模型及代码指纹。
- `REPORT.md`、`metrics.json`：可读报告与可复核指标。
- 每例目录：生成提示、模型原始输出、标准化对话、完整工作流报告、盲提取引文、逐例计分和运行日志。

重复运行相同命令会复用缓存并继续失败任务；不会按分数低重抽对话。要开始独立的新实验，指定新的 `--output analysis/evaluation_新编号`。不要在改变本体或提示词后复用旧实验目录。`failure.json` 是历史失败事件，不代表缓存恢复后的最终状态；最终完成情况以 `scored.json` 和汇总为准。

仅重算统计：

```powershell
python agent/evaluate_persona.py --aggregate-only
```

## 计分

8个行为维度×3个等级，对齐为24个规范标签。一个维度仅允许一个等级或缺失；缺失计漏报，错等级同时计错报和漏报。主指标Micro-F1；同时报告两种宏F1、覆盖率、Jaccard、Hamming loss、MAE、kappa和探索性ICC。置信区间按人物设定聚类重采样，保持同一设定的两份对话成组。

基线包括均匀随机标签、固定关键词规则、错配人物报告和直接读取对话的同模型盲提取。最后一项也用于检查对话生成保真度，不是人类金标准。

两份普通问答对照不参与恢复F1，单独统计无信息材料上的非空断言比例。非空预测必须引用原文连续子串；格式或引文不合法时降为缺失。引文存在只证明可追溯，不证明解释语义正确。

主指标保留全部计划案例，原流程失败按报告缺失计分。若做额外恢复实验，必须提前登记方法修订，创建该例的 `recovery.json`；恢复后的预测仅计入 `agent_after_recovery`，不能替代原流程主指标。首轮曾因输出预算不足而采用这一分离方式，详见本地报告。

## 必须保留的限制

- 同一个模型参与生成、分析和自动评分，有共享偏差；模型角色隔离不能替代独立模型与人工盲审。
- prompt_seed仅变化提示措辞，接口未指定随机种子。
- 6个人物设定不足以外推到真实人群；置信区间也受这一限制。
- 错等级率不是幻觉率，本体外结论的真实性仍需人工核验。
- 最终报告标记和现有产物审计通过，只表明流程完整，不等于内容准确。
- 低分用于提出下一步假设，后续调优需要新的留出集。
