# Agent Instructions

Read `README.md` and the relevant guide in `docs/` before changing behavior.

When finishing an optimization pass:

- summarize the changes and verification performed;
- keep public documentation consistent with the implementation;
- if a local `LONG_TERM_OPTIMIZATION_PLAN.md` exists, read it before optimization and update changed status or next steps. This local plan is not required to run or contribute to the project.

Do not commit or expose private conversation data by default. `talks/`, `analysis/`, `.env`, `.venv/`, and local CodeGraph database files are intentionally ignored.
