# Dialograph 本地分析工作区

界面沿用参考博客的暖白底色、衬线标题和细线双栏排版，功能直接连接现有 Python 工作流。没有前端依赖安装或构建步骤，需要 Python 3.10+。

在项目根目录运行：

```powershell
python agent/web_app.py
```

打开 http://127.0.0.1:5173 。端口被占用时使用 `python agent/web_app.py --port 5174`。请使用这个入口，直接打开 HTML 或使用静态文件服务不能执行分析。

## 使用流程

1. 从本地 `talks/` 选择对话，或点击“导入对话”，选择受支持的 JSON 或 Alpha Markdown。导入会创建唯一文件名并保留原始字节，不覆盖原文件。
2. 可在“其他需要隐藏的内容”逐行填写额外脱敏词，选择“仅预处理”或“完整分析”，然后启动。
3. 查看真实阶段、当前分块、已完成分块数和运行日志。没有按时间估算的假进度。
4. 阅读统计图表、关系分析、人物侧写、结构化证据等结果；可下载当前文件。
5. 完整分析完成后，在“检索与回查证据”输入关键词，按支持候选、反证、混合信号和存疑分组阅读；点击“回查原文”展开脱敏消息、引文高亮、分块、原始消息序号与时间。查询在本机完成，不调用模型。

仅预处理在本机完成，不调用模型。完整分析读取根目录 `.env` 的 `LLM_API_BASE`、`LLM_API_KEY`、`LLM_MODEL`，向配置的模型服务发送对话材料。页面显示模型和服务地址，不返回密钥。修改 `.env` 后重启服务。

预处理与完整分析默认先执行本机规则脱敏；统计、证据和报告使用脱敏文本。原始导出、输入快照与补充词仍保留在本机，已有未脱敏历史结果不自动改写。页面显示文本替换次数；日期、时间及间接身份线索仍可能保留，分享前请人工检查。详细规则与限制见 [数据脱敏说明](../docs/PRIVACY_REDACTION.md)。

当前接受 WeFlow JSON、统一协议 JSON v1 与 Alpha Markdown 私聊，单文件上限 50 MB；格式、可导入的合成样例和限制见 [聊天导入协议](../docs/CONVERSATION_INPUT.md)。其他导出工具须先转换为统一协议；不将任意 `text/sender` JSON 误当作兼容输入。

WeFlow 的 `isSend` 必须为整数 0/1，`type` 使用中文类型。统一协议显式声明两名参与者和发送者 ID；Alpha 消息头须出现导出账号及唯一对方。明确群聊标记、多人归属或无法确定发送者会被拒绝。

## 任务与结果

- 一次运行一个网页任务；关闭页面不停止后台分析。页面重开后可从“最近任务”查看状态。
- 可停止任务，已完成的分块保留。失败、停止或中断后可继续；恢复使用该 run 的实际分块参数，并复用已通过完整性检查的产物。
- 每个网页任务在 `analysis/web_jobs/{job_id}/` 保存输入快照、请求参数、状态和 `output/` 产物。与命令行的兼容输出路径分开，避免同名对象或新任务覆盖旧结果。
- 完整分析通过 `analysis_service.analyze_conversation` 与 CLI 共用报告复用、续跑和生成决策。关系报告与侧写分别经过暂存、审计和异常回滚；最终通过检查后才显示为完成。
- 网页任务历史只包含由网页创建的任务；已有命令行报告目前不会自动导入。
- 续跑会检查输入与流程指纹、原分块参数和缓存范围；自动继续时跳过不兼容旧缓存并显示提示，找不到兼容 run 则在当前任务内新建运行，旧缓存保留。证据摘要覆盖缩减会显示于完成提示和运行日志，完整证据仍可下载。报告输入另有按类别/时间轴分配的预算，不代表模型逐条看到全部证据。
- 页面支持 Markdown 的标题、段落、列表、引用、粗体、行内代码、代码块和表格；JSON 以格式化文本显示。报告内 HTML 不执行。
- “结构化证据”包含消息/证据编号、原文位置和隔离条目，可下载核对；未匹配或歧义引文不会进入报告证据材料，警告会显示在日志中。详细约定见 [原文绑定说明](../docs/EVIDENCE_GROUNDING.md)。
- 查询仅针对当前已完成的完整分析任务，隔离条目不进入网页检索。关键词匹配及原抽取置信度不能证明某个关系结论；某词没有匹配反证不代表整段对话没有反证。存疑不提供事实级引文锚点。
- 首次查询在任务下的 `retrieval/` 建立派生索引，服务重启后首次查询重新校验。账本、输入快照或补充脱敏词改变后旧版本不能用于回查，须重新检索；与账本不一致时拒绝查询。旧 v2 可用保存的任务快照在本机核对，不自动重新调用模型。详见 [本地证据检索](../docs/EVIDENCE_RETRIEVAL.md)。

服务仅监听 `127.0.0.1`，只开放前端静态文件及白名单结果接口；不把项目根目录作为静态目录。`talks/`、`analysis/`、`.env` 继续由 Git 忽略。

## 验证

```powershell
python -m unittest discover -s tests -v
node --check frontend/app.js
node --test tests/test_web_evidence_ui.js
```

测试使用合成数据。HTTP 集成测试启动本机临时服务；完整流程单元测试替换模型响应，不产生模型费用。`tests/fixtures/web_smoke.json` 可用于手动网页验证；选择完整分析会实际调用配置的模型。
